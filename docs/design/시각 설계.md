# 작업공간 시각 설계

작업공간(요건 정의 12장)의 색, 간격, 모서리, 그림자, 블러, 배경화면, 애니메이션을 정합니다. 무엇이 보이고 어떻게 조작되는지는 `화면 설계.md`, 서버의 상태 모델은 기술 설계 4.15, 이미지 파일의 취급은 `보안 설계.md` 7장을 따릅니다. 문서가 충돌하면 이 문서가 가장 뒤입니다(`화면 설계.md` 머리말).

이 문서의 숫자는 초안입니다. 디자인 시제품 측정(W-M6, 구축 절차 4.3) 뒤에 확정하며, "측정 대기"로 표시한 값은 그 전에 지시서에 쓰지 않습니다.

## 1. 목적과 범위

- 요건 WS-4(간격, 둥근 모서리, 포커스 테두리 그라데이션, 애니메이션), WS-13(그림자, 블러, 효과 수준), WS-14(배경화면)의 값과 규칙을 한곳에 둡니다.
- 클라이언트의 스타일 값은 이 문서의 토큰에서만 나옵니다. 패널 구현이 색이나 그림자를 따로 정하지 않습니다.
- 꾸밈은 기능을 가리지 않습니다. 효과를 모두 꺼도 같은 기능과 조작이 남고(요건 WS-13), 글자 대비 기준(6장)은 어떤 설정에서도 지킵니다.
- v1은 어두운 테마 하나입니다. 밝은 테마는 토큰 이름을 그대로 두고 값만 바꾸는 방식으로 뒤에 더합니다.

## 2. 참고한 서비스

도입하는 도구는 없습니다(ADR 0006). 개념과 값의 출발점만 가져옵니다.

| 서비스 | 가져온 것 | 가져오지 않은 것 |
| --- | --- | --- |
| Hyprland | dwindle(이진 트리, 가로세로 비율로 분할 방향 결정)와 master(주 영역 비율 기본 0.55), 전체화면의 두 모드(전체, 간격과 바를 남기는 최대화), 플로팅 창에만 적용되는 고정, 안쪽·바깥 간격, 둥근 모서리, 그라데이션 테두리, 그림자, 블러, 겹침 창 뒤 어둡게 하기 | 그릴 때마다 비율로 방향을 다시 정하는 기본 동작(ADR 0022), OS 창 관리, 창 규칙, 그룹 |
| Zellij | 고정한 플로팅 패널이 항상 위에 있는 동작, 플로팅 패널의 전체화면 | 쌓임(stacked) 패널, 플러그인 |
| Wave Terminal | 탭마다 이미지·그라데이션·색 배경과 불투명도를 지정하는 방식, 블록을 타일로 놓는 작업공간 | 화면에서 임의 경로의 이미지를 지정하는 방식, 내장 AI, 브라우저 블록 |
| Tern | 블록형 패널의 구성(요건 12장 B) | 요건 12장의 "채택하지 않는 Tern 기능" |
| Herdr, cmux | 주의가 필요한 에이전트를 배치와 무관하게 늘 보이는 자리에 표시 | 사이드바 중심 배치 |

## 3. 디자인 토큰

이름은 클라이언트 코드에서 그대로 씁니다. 단위가 없는 길이는 CSS 픽셀입니다.

**색**

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `bg` | `#0A0D12` | 배경화면이 없을 때의 바탕, 전체화면 패널의 바탕 |
| `panel` | `rgb(16 20 28)` | 패널 바탕. 불투명도는 6장 |
| `panel-raised` | `rgb(22 27 37)` | 패널 머리, 카드, 입력 칸 |
| `line` | `rgb(255 255 255 / 0.08)` | 포커스 없는 패널의 테두리, 구분선 |
| `text` | `#E7EAF0` | 본문, 터미널 기본 글자 |
| `text-muted` | `#9AA3B5` | 보조 글자, 표 머리 |
| `text-faint` | `#6B7385` | 꺼진 항목, 장식. 읽어야 하는 정보에는 쓰지 않음 |
| `accent-a`, `accent-b` | `#5EEAD4`, `#818CF8` | 포커스 테두리 그라데이션(135도), 선택 표시 |
| `ok` | `#4ADE80` | 통과, 완료, 살아 있음 |
| `warn` | `#FBBF24` | 경고, 대기, 승인 대기 |
| `danger` | `#F87171` | 실패, 차단, 입력 잠금 |
| `info` | `#60A5FA` | 실행 중, 링크 |

- 상태는 색만으로 알리지 않습니다. 글자나 아이콘을 함께 둡니다.
- 강조색 한 쌍은 공유 설정으로 바꿀 수 있습니다(10장). 상태 색은 바꾸지 않습니다.

**길이**

| 토큰 | 넓은 화면 | 좁은 화면 | Hyprland 대응 |
| --- | --- | --- | --- |
| `gap-in` (패널 사이) | 8 | 0 | `gaps_in` |
| `gap-out` (타일 영역 바깥) | 12 | 0 | `gaps_out` |
| `radius` (패널 모서리) | 12 | 0 (시트는 16) | `rounding` |
| `radius-inner` (카드, 칩, 버튼) | 8 | 8 | — |
| `border` (패널 테두리) | 1.5 | 0 | `border_size` |
| `bar-height` (상단 바) | 36 | 44 | — |
| `head-height` (패널 머리) | 30 | 40 | — |
| `touch-min` (터치 목표) | — | 44 | — |

- 패널이 하나뿐인 가상 화면에서도 간격과 테두리를 둡니다. 최대화와 구분되고 배경화면이 보이게 하기 위함입니다.
- 전체화면에서는 `gap`, `radius`, `border`가 모두 0입니다.

**글꼴**

| 토큰 | 값 |
| --- | --- |
| `font-ui` | 기기의 시스템 글꼴. 크기 13(넓은 화면), 15(좁은 화면) |
| `font-mono` | 고정폭 글꼴. 터미널·로그·diff에 씀. 크기 13, 줄 높이 1.35 |

터미널 글꼴을 클라이언트에 함께 실을지(세 기기에서 같은 글자 폭)와 어느 글꼴을 쓸지는 의존성 정책(`보안 설계.md` 6장)에 따라 M20에서 정합니다.

## 4. 패널 외형

**구성**: 패널은 머리와 내용으로 이루어집니다.

| 자리 | 내용 |
| --- | --- |
| 머리 왼쪽 | 패널 종류 아이콘, 제목(터미널은 tmux 창 이름, 작업 패널은 작업 id) |
| 머리 가운데 | 상태 배지: 입력 소유 기기, 입력 잠금, 읽기 전용, 끝남, 고정 |
| 머리 오른쪽 | 고정 버튼(플로팅일 때), 패널 메뉴 |
| 내용 | 패널 종류별 화면 |

- 포커스된 패널은 테두리를 `accent-a` → `accent-b` 그라데이션으로, 그 밖의 패널은 `line`으로 그립니다. 포커스는 테두리로만 알리고 내용의 밝기는 바꾸지 않습니다. 여러 패널을 동시에 읽는 화면이기 때문입니다.
- 고정 패널은 포커스가 없을 때도 `accent-b`를 0.5 불투명도로 테두리에 씁니다.
- 승인 대기 중인 메인 터미널 패널은 테두리를 `warn`으로 그립니다. 포커스 그라데이션보다 우선합니다.
- 최대화한 패널의 머리에는 그 가상 화면의 타일 패널 수(예: `2/5`)를 보입니다. 가려진 패널이 있음을 알리기 위함입니다.

**최소 크기** (넓은 화면, 측정 대기)

| 패널 | 최소 너비 × 높이 |
| --- | --- |
| 터미널 | 80열 × 12행에 해당하는 크기 |
| 실행 로그, diff | 60열 × 10행에 해당하는 크기 |
| 작업 보드, 병합 표 | 480 × 240 |
| 그 밖 | 320 × 200 |
| 플로팅·고정 패널 | 280 × 160 (터미널은 위의 터미널 기준) |

## 5. 그림자

높이 단계로 겹침 순서를 알립니다. 단계는 `화면 설계.md` 3.1의 층을 따릅니다.

| 단계 | 대상 | 그림자 | Hyprland 대응 |
| --- | --- | --- | --- |
| 0 | 전체화면 패널, 좁은 화면의 패널 | 없음 | — |
| 1 | 타일 패널 | `0 2px 8px rgb(0 0 0 / 0.25)` | `shadow` |
| 2 | 포커스된 타일 패널 | `0 8px 24px rgb(0 0 0 / 0.35)` | `shadow` |
| 3 | 플로팅 패널 | `0 16px 40px rgb(0 0 0 / 0.45)` | `shadow` |
| 4 | 고정 패널 | `0 20px 48px rgb(0 0 0 / 0.50)` | `shadow` |
| 5 | 스크래치패드, 명령 팔레트, 시트 | `0 24px 64px rgb(0 0 0 / 0.55)`, 뒤를 0.4만큼 어둡게 | `dim_around` |

- 그림자는 패널 바깥에만 그립니다. 반투명한 패널 안쪽으로 비치지 않게 합니다.
- 포커스가 옮겨 갈 때 단계 1과 2 사이는 애니메이션으로 바꿉니다(8장).
- 그림자 색은 검정 한 가지입니다. 강조색 빛(glow)은 쓰지 않습니다.

## 6. 블러와 가독성

패널 바탕을 반투명하게 하고, 그 뒤에 비치는 것을 흐리게 합니다.

**불투명도와 블러**

| 대상 | `panel` 불투명도 기본 | 하한 | 블러 반경 |
| --- | --- | --- | --- |
| 터미널, 실행 로그, diff | 0.90 | 0.85 | 24 |
| 그 밖의 패널 | 0.80 | 0.72 | 24 |
| 패널 머리 | 패널보다 0.05 높게 | — | — |
| 상단 바 | 0.60 | 0.50 | 24 |
| 플로팅·고정 패널, 스크래치패드, 명령 팔레트 | 0.88 | 0.80 | 16 |
| 전체화면 패널 | 1.00 | — | 없음 |

**대비 기준**

- `text`는 4.5:1 이상, `text-muted`는 3:1 이상을 모든 허용 설정에서 지킵니다. 기본값에서는 `text-muted`도 4.5:1 이상입니다.
- 기준은 가장 나쁜 경우인 흰색 배경화면으로 계산합니다. 블러는 밝기 평균을 바꾸지 않으므로 계산에 넣지 않습니다.

| `panel` 불투명도 | 배경 딤 | `text` | `text-muted` | 비고 |
| --- | --- | --- | --- | --- |
| 1.00 | — | 15.3 | 7.3 | 효과 수준 `끔`, 전체화면 |
| 0.90 | 0.35 | 13.1 | 6.2 | 터미널 기본값 |
| 0.80 | 0.35 | 10.8 | 5.1 | 일반 패널 기본값 |
| 0.85 | 0.20 | 11.0 | 5.2 | 터미널 하한 |
| 0.72 | 0.20 | 7.7 | 3.6 | 일반 패널 하한 |

- 배경 딤(7장)의 하한은 이미지 배경에서 0.20입니다. 불투명도와 딤이 하한보다 낮은 설정은 서버가 받지 않습니다.
- 터미널의 ANSI 색은 `panel` 위에서 3:1 이상이 되는 팔레트 하나를 정해 씁니다(M21).

**그리는 방식** (구현 지침, 측정 대기)

- 타일 패널은 서로 겹치지 않으므로 뒤에 비치는 것은 배경화면뿐입니다. 배경화면을 한 번 흐리게 만든 그림을 패널 바탕에 같은 위치로 맞춰 그리면 실시간 블러가 필요 없습니다.
- 실시간 블러(`backdrop-filter`)는 다른 패널 위에 겹치는 것(플로팅, 고정, 스크래치패드, 명령 팔레트, 시트)에만 씁니다.
- 터미널 글자를 그리는 영역 자체에는 블러와 반투명을 걸지 않고, 패널 바탕에만 겁니다.
- 두 방식의 비용과 iOS 동작은 디자인 시제품에서 재고(`화면 설계.md` 7장), 실시간 블러가 프레임을 지키지 못하는 기기는 효과 수준 `절약`을 기본값으로 둡니다.

## 7. 배경화면

**종류**

| 종류 | 내용 |
| --- | --- |
| 내장 배경 | 클라이언트가 그라데이션으로 그리는 배경. 이미지 파일이 아니므로 저장소에 그림을 넣지 않음 |
| 단색 | `bg` 또는 사용자가 고른 색 |
| 등록 이미지 | 맥 호스트에서 `orch workspace wallpaper add <파일>`로 등록한 이미지(`보안 설계.md` 7장) |

**내장 배경** (어두운 바탕 위에 번지는 색 두세 개)

| 이름 | 바탕 | 번지는 색 |
| --- | --- | --- |
| `abyss` (기본) | `#070B14` | `#134E4A`, `#312E81` |
| `dawn` | `#120B18` | `#6D28D9`, `#9D174D`, `#7C2D12` |
| `forest` | `#07110C` | `#14532D`, `#164E63` |
| `ember` | `#140C08` | `#7C2D12`, `#713F12` |
| `graphite` | `#0D0F13` | `#1F2937` |

**지정과 표시**

- 전체 기본값 하나와 가상 화면마다의 지정을 둡니다. 지정이 없는 가상 화면은 전체 기본값을 씁니다. 공유 상태입니다.
- 이미지는 화면을 채우도록 비율을 지키며 잘라 그립니다(cover). 잘리는 기준점(가로·세로 0~1)을 이미지마다 저장합니다. 기기의 화면 비율이 달라도 같은 부분이 중심에 옵니다.
- 배경 딤: 배경화면 위에 `bg`를 덮는 정도입니다. 기본 0.35, 이미지 배경의 범위는 0.20~0.80, 내장 배경과 단색은 0~0.80입니다.
- 가상 화면을 전환하면 배경화면도 함께 바뀝니다(8장).
- 스크래치패드와 시트 뒤에서는 5장의 어둡게 하기가 더해집니다.

**이미지 제한**

| 항목 | 값 |
| --- | --- |
| 형식 | PNG, JPEG, WebP. SVG와 움직이는 이미지는 받지 않음 |
| 파일 크기 | 10 MB 이하 |
| 등록 수 | 20개 이하 |

## 8. 모션

| 동작 | 시간 | 모습 |
| --- | --- | --- |
| 패널 열기, 닫기 | 160 ms | 0.96배에서 커지며 나타남, 반대로 사라짐 |
| 패널 이동, 크기 변화(다른 패널이 열리거나 닫혀 다시 배치될 때) | 220 ms | 위치와 크기를 이어서 바꿈 |
| 포커스 이동 | 120 ms | 테두리와 그림자 단계 전환 |
| 최대화, 전체화면 | 200 ms | 패널이 제자리에서 커짐. 간격과 모서리도 함께 바뀜 |
| 가상 화면 전환 | 260 ms | 가로로 밀림. 배경화면은 겹쳐 바뀜 |
| 스크래치패드, 명령 팔레트 | 180 ms | 넓은 화면은 0.98배에서 커지며 나타남, 좁은 화면은 아래에서 올라옴 |
| 고정 전환 | 160 ms | 테두리 전환, 그림자 단계 3 ↔ 4 |

- 가속 곡선은 한 가지를 씁니다: 빠르게 시작해 부드럽게 멈춤(`cubic-bezier(0.2, 0.8, 0.2, 1)`).
- 애니메이션은 위치와 크기를 바꾸는 변환과 불투명도로만 합니다. 애니메이션 중에는 패널 내용의 배치를 다시 계산하지 않습니다.
- 터미널의 행·열 변경은 애니메이션이 끝난 뒤 한 번만 보냅니다.
- 경계를 끄는 동안과 플로팅 패널을 끄는 동안은 애니메이션 없이 손가락과 포인터를 그대로 따라갑니다.
- 다른 기기의 조작으로 바뀐 배치도 같은 애니메이션으로 보입니다. 무엇이 바뀌었는지 알 수 있게 하기 위함입니다.

## 9. 효과 수준

기기마다 고릅니다. 서버가 기기별로 기억하므로 다시 접속해도 유지됩니다(ADR 0023).

| 항목 | `전체` | `절약` | `끔` |
| --- | --- | --- | --- |
| 간격, 모서리, 테두리, 포커스 그라데이션 | 켬 | 켬 | 켬 |
| 배경화면 | 켬 | 켬 | 단색 `bg` |
| 그림자 | 5장 그대로 | 단계 3 이상만 | 없음. 겹치는 패널은 테두리로 구분 |
| 타일 패널의 블러 (미리 흐리게 한 배경) | 켬 | 켬 | 없음, 불투명도 1.00 |
| 실시간 블러 | 켬 | 없음, 불투명도 0.96 | 없음, 불투명도 1.00 |
| 애니메이션 | 8장 그대로 | 열기·닫기와 포커스만, 나머지는 즉시 | 없음 |

- OS의 "동작 줄이기"가 켜져 있으면 애니메이션을 `끔`과 같게, "투명도 줄이기"가 켜져 있으면 블러와 불투명도를 `끔`과 같게 합니다. 효과 수준보다 우선합니다.
- 프레임을 재서 수준을 자동으로 낮추는 동작은 v1에 넣지 않습니다.

## 10. 설정 항목

모양 설정은 명령 팔레트에서 여는 겹침 화면 하나에 둡니다(`화면 설계.md` 4장).

| 항목 | 범위 | 기본값 | 저장 |
| --- | --- | --- | --- |
| 배경화면 (전체 기본값) | 내장 배경, 단색, 등록 이미지 | `abyss` | 공유 |
| 배경화면 (가상 화면별) | 위와 같음, "기본값 따름" | 기본값 따름 | 공유 |
| 배경 딤 | 7장의 범위 | 0.35 | 공유 |
| 패널 불투명도 (터미널류, 그 밖) | 6장의 하한 ~ 1.00 | 0.90, 0.80 | 공유 |
| 강조색 한 쌍 | 준비된 쌍 중에서 선택 | `#5EEAD4`, `#818CF8` | 공유 |
| 간격 (`gap-in`, `gap-out`) | 0~24 | 8, 12 | 공유 |
| 모서리 (`radius`) | 0~20 | 12 | 공유 |
| 효과 수준 | `전체`, `절약`, `끔` | 측정 대기 | 기기별 |

- 공유 설정은 한 기기에서 바꾸면 모든 기기에 반영됩니다. 기기별 설정은 그 기기에서만 바꿉니다.
- 클라이언트는 설정을 기기에 저장하지 않습니다. 화면 상태는 서버가 가집니다(ADR 0007).
- 범위를 벗어난 값은 서버가 거부합니다.

## 11. 성능 지침

- 목표 프레임과 기기별 통과 기준은 측정 대기입니다(W-M6 디자인 시제품).
- 실시간 블러를 쓰는 요소는 한 화면에 고정 패널 상한(기본 3) + 플로팅 + 겹침 화면 하나를 넘지 않게 합니다. 넘으면 포커스 없는 플로팅 패널부터 실시간 블러를 끕니다.
- 미리 흐리게 한 배경화면은 배경화면이나 화면 크기가 바뀔 때만 다시 만듭니다.
- 로그와 터미널 출력이 흐르는 동안에는 그 패널의 그림자와 테두리를 다시 그리지 않게 층을 나눕니다.
- 화면에 보이지 않는 가상 화면의 패널은 그리지 않습니다. 전체화면에 가려진 패널도 같습니다. 데이터 구독은 유지합니다.
