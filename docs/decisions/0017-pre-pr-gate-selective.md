# 0017. G2_PRE_PR도 선택 실행

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: 기술 설계 4.14, ADR 0009

## 맥락

ADR 0009는 G2_PRE_PR에서 전체를 돌릴지를 T-M1 결과로 정하기로 했습니다. T-M1(2026-11-15)에서 `src/orch`를 바꾼 최근 머지 PR 29건 모두, 정적 import 선택이 실제로 쓰인 테스트 묶음을 놓치지 않았습니다. 선택 시간은 PR당 중앙값 525초로, 전체 838초보다 약 37% 짧습니다.

## 선택지

1. G2_PRE_PR도 rebase 뒤의 기준으로 다시 골라 선택 실행
2. G2만 선택 실행하고 G2_PRE_PR은 항상 전체

## 결정

1을 택합니다. 안전 장치 경로, L3·L3R, 전체 실행 조건(기술 설계 4.14 규칙 3)에 해당하면 G2_PRE_PR도 전체를 돌립니다.

## 결과

- 선택이 놓친 실패는 하루 한 번의 맥 전체 실행과, 검증 세션이 머지 전에 돌리는 합본 전체 실행이 잡습니다.
- 실패한 테스트 이름을 게이트 결과에 남겨, 다음 되짚기는 실제 실패로 합니다.
