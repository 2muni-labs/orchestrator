# 결정 기록 (ADR)

설계 문서(`docs/design/`)에 반영된 결정을 결정 하나에 파일 하나로 기록합니다. 설계 문서가 "무엇을 하는가"의 원본이라면, 이 디렉터리는 "왜 그렇게 정했는가"의 원본입니다.

## 규칙

- 파일 이름은 `NNNN-<영어 슬러그>.md`, 번호는 순서대로 붙이고 다시 쓰지 않습니다.
- 본문은 한국어이며 아래 형식을 따릅니다.
- 결정을 바꿀 때는 기존 파일을 고치지 않고 새 ADR을 쓴 뒤, 기존 파일의 상태를 `대체됨 (NNNN)`으로만 바꿉니다.
- 설계 문서에는 결정 내용을 쓰고, 근거 대신 `(ADR NNNN)`으로 링크합니다.
- 다른 설계 문서와 마찬가지로 PR로만 바꿉니다.

## 형식

```
# NNNN. 제목

- 상태: 결정됨 | 대체됨 (NNNN)
- 날짜: YYYY-MM-DD
- 관련 문서: 설계 문서의 장·절

## 맥락
## 선택지
## 결정
## 결과
```
