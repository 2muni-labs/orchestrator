# 0014. 안전 장치 경로 작업의 리뷰 필수

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: 요건 9장, 기술 설계 4.5, 4.6, 4.14, `보안 설계.md` 3장

## 맥락

교차 리뷰(G4)는 L3·L3R 등급이나 지시서의 `review = true`일 때만 돕니다(`gate.review_required`). 안전 장치 경로(`targets.toml`의 `safety_paths`)를 바꾸는 작업은 PR 단계에서 user check가 될 뿐, 등급이 L2면 리뷰 없이 PR까지 갑니다. Codex 우선 배분(ADR 0012)으로 L3를 아껴 쓰면서 이 틈이 커집니다.

## 선택지

1. 지시서 작성 때 메인이 `review = true`를 붙이는 규칙만 둠
2. 게이트가 변경 경로를 `safety_paths`와 대조해 리뷰를 강제

## 결정

2를 택합니다. 변경 경로가 대상의 `safety_paths`에 하나라도 걸리면 등급과 관계없이 `reviewing`으로 보냅니다. 구현은 `m-p5-safety-review`(M18)이며, 그 전까지는 1의 규칙을 메인이 지킵니다. 같은 작업은 선택 실행에서도 전체 테스트를 돌립니다(ADR 0009).

## 결과

- 안전 장치 경로를 바꾸는 작업은 리뷰와 user check를 모두 거칩니다.
- `gate.py` 자체가 안전 장치 경로이므로 이 작업은 L3로 배분합니다.
