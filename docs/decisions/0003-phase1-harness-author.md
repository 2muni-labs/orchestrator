# 0003. Phase 1 하네스 초안 작성 위치

- 상태: 결정됨
- 날짜: Phase 1
- 관련 문서: 구축 절차 2장 Phase 1

## 맥락

orch가 없는 상태에서 하네스(`AGENTS.md`, `CLAUDE.md`, 훅, 템플릿)를 먼저 만들어야 했습니다.

## 선택지

1. 사용자가 직접 작성
2. 허브 저장소에서 메인(Claude Code)이 작성하고 사용자가 PR로 검토

## 결정

2를 택합니다.

## 결과

- 하네스도 처음부터 PR 검토를 거쳤습니다.
- 이후 하네스 변경은 허브 대상 세션의 하네스 PR로만 합니다.
