# 0015. 메인 창 입력은 신뢰 기기에만

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: `보안 설계.md` 4장, 11장, 요건 12장

## 맥락

작업공간은 여러 기기에서 메인 Claude Code 창에 입력할 수 있게 합니다. 측정(S-M1, Claude Code 2.1.319)에서 `!` bash 모드로 넣은 명령은 PreToolUse 훅을 거치지 않았습니다. 두 번 측정했고, 두 번 모두 명령이 실행됐으며 도구 이벤트는 기록되지 않았습니다. guard와 deny 규칙은 이 경로를 보지 못하므로, 메인 창에 입력할 수 있는 기기는 guard 없는 셸을 가진 것과 같습니다.

## 선택지

1. 입력 권한을 맥과 같은 신뢰 수준의 기기에만 주고, 나머지 기기는 읽기 전용으로 둠
2. 1에 더해 작업공간 서버가 줄 맨 앞의 `!` 입력을 거부함
3. 모든 기기에 입력을 허용하고 guard에 의존함

## 결정

1을 택합니다. 2는 붙여넣기, 입력 방식, Claude Code의 다른 입력 경로로 우회될 수 있어 방어선으로 삼지 않습니다. 3은 측정 결과로 성립하지 않습니다.

## 결과

- 작업공간의 입력 권한은 기기별 허용 목록(W-M7)으로 주며, 허용 기준은 "그 기기를 잃어도 맥 셸을 내준 것과 같다고 받아들일 수 있는가"입니다.
- 입력 감사 기록, 입력 잠금(`orch workspace lock`), 기기 분실 런북(`보안 설계.md` 9장)은 그대로 둡니다.
- Claude Code 버전을 올릴 때 S-M1을 다시 측정합니다(`config/pins.toml`).
