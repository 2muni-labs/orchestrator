# 0006. Tern과 Hyprland를 도입하지 않음

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: 요건 11장, 12장, 실행 설계 4장, `화면 설계.md` 3장

## 맥락

Tern은 터미널·원격 접속 도구로 시범 평가 중이었고, Hyprland식 타일 배치가 원하는 조작감이었습니다.

## 선택지

1. Tern을 채택하고 orch 기능을 덧붙임
2. 필요한 기능만 작업공간으로 직접 구현, Hyprland는 개념만 구현

## 결정

2를 택합니다. Tern 시범 평가를 끝내고, Hyprland(Linux Wayland 전용)도 도입하지 않고 조작 개념과 시각적 느낌만 작업공간 안에서 구현합니다. Hyprland의 workspace 개념은 "가상 화면"으로 부릅니다.

## 결과

- 작업공간 v1 출시 전까지 관찰 화면은 지금의 tmux 배치와 `orch watch --panels`입니다.
- 외부 도구에 대한 의존이 줄고, 구현 범위는 늘어납니다.
