# 0022. dwindle 분할 방향은 열 때 정해 트리에 저장

- 상태: 제안 (머지할 때 "결정됨"으로 바꿈)
- 날짜: 2026-11-17
- 관련 문서: 요건 WS-4, WS-10, `화면 설계.md` 3.2, 기술 설계 4.15

## 맥락

`화면 설계.md`는 dwindle의 분할 방향이 "번갈아 바뀐다"고만 정했습니다. Hyprland의 dwindle은 부모 영역의 가로세로 비율로 방향을 정하고, 기본 설정에서는 그릴 때마다 다시 정합니다. 작업공간은 화면 비율이 다른 기기(Windows 가로, iPad 세로)가 같은 분할 트리를 공유하고, 서버는 기기의 화면 크기를 모릅니다.

## 선택지

1. 트리 깊이에 따라 좌우와 상하를 번갈아 씀
2. 패널을 열 때 나뉘는 패널의 가로세로 비율로 정하고 트리에 저장 (Hyprland의 `preserve_split`에 해당)
3. 그릴 때마다 기기의 화면에서 다시 정함 (Hyprland 기본 동작)

## 결정

2를 택합니다. 방향은 조작한 기기가 자기 화면에서 정해 조작 메시지에 명시하고, 서버는 받은 방향을 저장합니다. 사용자가 방향 전환 조작으로 바꿀 수 있습니다.

- 1을 택하지 않은 이유: 세로로 긴 패널을 다시 좌우로 나누는 경우가 생겨 좁은 패널이 만들어집니다.
- 3을 택하지 않은 이유: 기기마다 배치가 달라져 "오른쪽 패널"이 기기마다 다른 패널을 가리키고, 경계 드래그로 바꾼 비율이 다른 기기에서는 다른 방향에 적용됩니다.

## 결과

- 넓은 화면 기기들은 같은 배치를 봅니다. 가로 화면에서 만든 배치는 세로 화면에서 최적이 아닐 수 있고, 사용자가 방향 전환으로 고칩니다.
- 서버는 화면 크기를 몰라도 되고, 조작을 받은 순서대로 적용하는 모델(기술 설계 4.15)이 그대로 유지됩니다.
- 조작 메시지 스키마(`schemas/workspace/`)의 패널 열기에 방향이 필수 값으로 들어갑니다.
