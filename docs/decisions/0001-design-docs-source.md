# 0001. 설계 문서의 원본 위치

- 상태: 결정됨
- 날짜: Phase 1
- 관련 문서: 구축 절차 2장, `AGENTS.md`

## 맥락

Phase 0까지 설계 문서는 저장소 밖에서 작성됐습니다. 에이전트가 같은 문서를 읽고, 변경 이력을 남겨야 했습니다.

## 선택지

1. 저장소 밖 문서를 원본으로 두고 필요할 때 복사
2. 허브 저장소의 `docs/design/`을 원본으로 두고 PR로만 변경

## 결정

2를 택합니다. Phase 1 이후에는 허브 저장소의 `docs/design/`이 원본이며 설계 변경은 PR로만 반영합니다. `구축 절차.md`는 Phase 1 시점의 내보내기 원본으로 보존합니다.

## 결과

- 모든 에이전트가 같은 문서를 읽고, 변경은 리뷰를 거칩니다.
- 문서 변경도 하네스 PR이 되어 사용자 확인 대상이 됩니다.
