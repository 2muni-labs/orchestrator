# 0007. 기기 간 같은 경험과 공유 상태

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: 요건 NF-7, WS-7, `화면 설계.md` 3장, 5장

## 맥락

Windows, iPhone, iPad에서 "같은 경험"의 뜻과, 기기 사이에 무엇을 공유할지 정해야 했습니다.

## 선택지

1. 기기마다 다른 기능과 배치
2. 같은 기능과 상태, 배치만 화면 크기와 입력 수단에 맞춤
3. 2에 더해 지금 보고 있는 가상 화면과 포커스까지 공유

## 결정

3을 택합니다. 기기별 전용 기능은 두지 않고, 가상 화면 목록, 분할 트리, 플로팅 패널, 열린 패널, 지금 보고 있는 가상 화면, 포커스를 서버가 가지고 모든 기기가 공유합니다.

## 결과

- 한 기기의 조작이 다른 기기 화면을 바꿉니다. 입력이 겹칠 때의 규칙(입력 소유권)과 공유를 잠시 끄는 방법이 필요합니다(`화면 설계.md` 4장, `보안 설계.md` 4장).
- 세 기기 모두 같은 인수 시나리오를 통과해야 출시합니다.
