# 0009. 테스트 묶음과 선택 실행

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: 요건 12장 테스트, 기술 설계 4.14

## 맥락

전체 테스트가 약 14분 반(3990건)이 되어 게이트 시간 제한에 가까워졌고, 작업공간 테스트까지 더해질 예정이었습니다.

## 선택지

1. 계속 전체 실행
2. 파이프라인과 작업공간, 기존 테스트를 기능 묶음으로 나누고 변경된 부분만 실행

## 결정

2를 택합니다. 변경 경로와 import 관계로 묶음을 고릅니다. 전체 실행 조건은 테스트 기반·의존성·`targets.toml`·묶음 대응이 바뀔 때, 버전 PR, 하루 한 번 기본 브랜치입니다. 2026-11-15 보안 리뷰에 따라 안전 장치 경로를 바꾸는 작업과 L3 작업도 전체를 돌립니다.

## 결과

- 선택이 영향을 놓칠 위험이 생깁니다. 선택 실행을 켜기 전에 최근 머지된 PR로 되짚고(T-M1), 하루 한 번 전체 실행과 검증 세션의 전체 실행으로 줄입니다.
- `G2_PRE_PR`의 선택 여부는 T-M1 뒤에 정합니다.
