# 0031. 5a 무인 운용의 선행 조건에서 기기 분실 런북을 뺌

- 상태: 결정됨
- 날짜: 2026-11-25
- 관련 문서: 구축 절차 4.3, `보안 설계.md` 9장, 요건 12장

## 맥락

ADR 0004는 Phase 5를 5a(운용 점검)와 5b(작업공간)로 나누고, 5a의 1주일 무인 운용 전에 기기 분실
런북(`보안 설계.md` 9장)을 갖추도록 했습니다. M19까지 설치한 뒤 운용을 시작하려 할 때, 사용자는
5a 운용에서 기기 분실을 고려할 필요가 없다고 정했습니다. 5a는 현재 tmux 구성으로 운용하며, 원격
입력을 받는 작업공간은 5b에서 만듭니다.

## 선택지

1. ADR 0004대로 런북 적용 준비를 확인한 뒤 운용을 시작
2. 런북 확인을 5a의 선행 조건에서 빼고 바로 운용을 시작

## 결정

2를 택합니다. ADR 0004의 나머지 결정은 그대로 이어 받습니다.

- Phase 5는 허브에서 작업공간을 개발하며 1주일 이상 무인 운용하는 단계입니다. 다른 실제 대상
  저장소 등록은 Phase 6으로 미룹니다.
- **5a 운용 점검**: M17~M19와 현재 tmux 구성으로 1주일 무인 운용
- **5b 작업공간**: M20~M21
- 5a 직후 실제 대상 하나를 등록할지는 5a를 마칠 때 정합니다(요건 13장).
- 기기 분실 런북(`보안 설계.md` 9장)은 문서로 남기지만, 5a 운용의 선행 조건이 아닙니다.

## 결과

- 5a의 1주일 무인 운용은 M17~M19 설치와 `m-p5-safety-review`·`m-p5-codex-sandbox` 설치만으로
  시작합니다.
- 기기 분실은 5a의 위험 평가에 넣지 않습니다. 실제로 분실이 생기면 런북을 따르되, 적용 준비는
  확인하지 않은 상태입니다.
- 작업공간 서버는 여전히 5a의 운용 결과와 보안 측정(S-M1~S-M3) 뒤에 시작합니다.
