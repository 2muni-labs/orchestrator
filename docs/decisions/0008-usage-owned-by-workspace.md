# 0008. 토큰 사용량과 한도는 작업공간이 맡음

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: 요건 12장 D, 기술 설계 4.15

## 맥락

에이전트별 토큰 사용량과 5시간·주간 한도를 보여 주려면 에이전트 세션 기록을 읽어야 합니다. 파이프라인(`runs` 표)에 넣을지 작업공간에 둘지 정해야 했습니다.

## 선택지

1. 파이프라인이 실행마다 토큰을 기록(`runs`에 열 추가, `orch usage`)
2. 작업공간이 세션 기록에서 직접 집계

## 결정

2를 택합니다. 버전 고정과 업그레이드 판단은 파이프라인이, 토큰 사용량과 한도는 작업공간이 맡습니다. `BLOCKED_QUOTA` 분류는 배분 판단에 쓰이므로 파이프라인에 남습니다.

## 결과

- 파이프라인의 스키마와 실행기에 사용량 코드가 들어가지 않습니다.
- 작업공간이 에이전트 세션 기록을 읽으므로, 기록 파서를 안전 장치로 다룹니다(`보안 설계.md` 7장).
