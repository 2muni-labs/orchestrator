# 0011. 웹 클라이언트(PWA) 1차 결정

- 상태: 결정됨
- 날짜: 2026-11-15
- 관련 문서: 기술 설계 4.15, `화면 설계.md` 7장

## 맥락

Windows, iPhone, iPad에서 한 코드베이스로 같은 경험을 내야 합니다.

## 선택지

1. 웹 클라이언트(PWA)
2. 크로스 플랫폼 네이티브(Tauri 등)
3. 기기별 네이티브 앱

## 결정

PWA로 1차 결정합니다. 측정(W-M6)에서 iOS 제약(단축키 가로채기, 백그라운드 연결)이 치명적이면 다시 정합니다. 서버와 클라이언트의 언어와 프레임워크는 측정 뒤 정합니다.

## 결과

- 앱 서명과 배포가 필요 없습니다.
- 브라우저 저장소에 로그가 남지 않게 해야 합니다(`보안 설계.md` 7장).
